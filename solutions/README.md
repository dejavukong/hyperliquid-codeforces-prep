# 题解目录

把每题的代码放这里，命名用 `题号.cpp`，例如 `45C.cpp`、`380C.cpp`。

建议每个文件顶部写一段注释：
```cpp
// 45C Dancing Lessons — 堆 + 双向链表 + 惰性删除
// 思路：所有相邻对入小根堆(差值,左下标)；双向链表维护相邻关系；
//       弹堆跳过失效对，配对后删两点、连接左右邻居、新相邻对入堆。
// 复杂度：O(n log n)
// HL 映射：撮合引擎本体 — price-time priority + 撤单失效
```

C++ 优先（引擎是性能敏感代码）。编译：`g++ -O2 -std=c++17 45C.cpp -o bin/45C`
